# The Ductus guide

Ductus describes a typeface as a Python program and compiles it to
OpenType. This guide explains how to use it; the
[reference manual](../../README.md) explains how the compiler works inside.

1. **[Getting started](getting-started.md)**: install, build the example
   faces, look at proofs, write a first glyph.
2. **[The language](language.md)**: parameters, pens, strokes and paths,
   parts and inheritance, bowls, lobes and joins, terminals, cuts,
   composites, overrides, naming.
3. **[Building fonts](building.md)**: the kit and its style options,
   spacing and kerning, variable fonts and their masters, optical sizes,
   italics, ink traps and tidying.
4. **[Tools](tools.md)**: every `ductus` command, the live editor, the
   browser editor, and the benchmark and fitting tools.

Design logs, one entry and one sheet per iteration:
- [Ductus Sans](../sans/README.md)
- [Ductus Display](../display_serif/README.md)
- [Ductus Notch](../notch/README.md)

Run every command in this guide from the `ductus/` folder of the
repository, the one that holds `pyproject.toml`.
